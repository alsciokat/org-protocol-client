Help

What this extension does

Click the toolbar icon (or press Ctrl+Shift+X, ⌘⇧X on Mac) to open a menu of your protocols. Picking one builds an org-protocol:// link from the current page and hands it to Emacs.

Protocols

A protocol is one kind of link: a sub-protocol (the handler on the Emacs side), an optional template key, and the parameters to include. Add as many as you like — each becomes an entry in the capture menu.

Template key

Matches a key in your org-capture-templates. Set a fixed key, or select the Template parameter instead to be asked for a key each time you capture.

Quick capture

Skips the menu and immediately sends one of the two default protocols, chosen by whether text is selected on the page.

Advanced

Sub-protocols define which parameters each Emacs handler accepts. Parameters define the query key each value is sent under and where the value comes from (page URL, page title, selected text, or a template key). Edit these only if your Emacs setup expects something custom.

Emacs setup

Emacs must load org-protocol, run (server-start), and your OS must register emacsclient as the handler for org-protocol:// links. See the README for step-by-step instructions.
